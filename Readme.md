## Лабораторная работа № 2

**Тема:** Разработка многостраничного web-сайта с использованием HTML и CSS.
**Тематика сайта:** Личный профиль и страница «О моем коте».

### Описание проекта
Проект представляет собой статический веб-сайт, состоящий из 3 страниц:
1. `index.html` — Главная страница с полноэкранным фоновым изображением.
2. `about-me.html` — Страница «Обо мне» с карточкой профиля и ссылками на социальные сети.
3. `about-cat.html` — Страница «О моем коте» с подробной информацией, таблицей статистики и сеткой изображений.
